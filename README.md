# DataTable

[Deutsch](README.de.md) | English

IP-Symcon library by Ueli Schweizer / Cassanis Automation.

| Module | Description |
|---|---|
| [DataTable](DataTable/README.md) | Small structured data sets with freely defined fields, edited in an HTML tile |

## Requirements

IP-Symcon 8.1 or later. From 9.1, the tile can also be shown in fullscreen mode.

## Installation

Via the Module Store, or in Module Control with the URL
`https://github.com/wowbagger60/DataTable`.
